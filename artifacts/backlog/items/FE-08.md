## What

Azure DevOps, or whichever platform comes second. GitHub is the first adapter, not the only intended
one.

## Why

Every gate semantic is already asserted against an injected platform specifically so a second adapter
changes none of them. The boundary exists; nothing has been built behind it.

## Notes

Seeded from the README's *What this does not do yet*. Not scheduled.

Worth knowing before starting: M4 established that the GitHub semantics themselves were weaker than
their documentation. A second adapter written from documented responses would inherit that risk, not
avoid it.
