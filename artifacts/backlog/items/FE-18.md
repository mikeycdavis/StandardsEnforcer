C-A and C-C from the [M3 reconciliation](../../evidence/2026-08-12-m3-reconciliation.md), implemented
as **one slice**, because a digest with no authoritative surface to describe is a digest of nothing.

## What

Until this, the only recorded basis for a scope decision was `reviewedFootprint` — the sorted set of
*kinds* of ML evidence, digested. That was a reasoned choice: digesting content would manufacture
churn from ordinary commits, while a repository that gains or loses a whole kind of evidence has
genuinely changed.

**It fails one-directionally, in the dangerous direction.** A repository can acquire a great deal of
first-party prediction code without acquiring a new *kind* of signal — a tenth model file where one
already existed, a new inference path in a repository already importing an inference client. The kind
set is identical, the digest matches, and a determination made when the repository was far smaller
reads as current.

## The model, per [ADR 0007](../../adr/0007-the-review-surface-is-the-whole-repository.md)

```text
whole tracked repository − explicit, reasoned exclusions
        ↓
canonical reviewed surface
        ↓
surfaceDigest    resolver semantics + exclusion configuration
contentDigest    canonical tracked tuples inside the surface
        ↓
observed + equal      → current
observed + different  → stale
not observable        → undetermined
        ↓
stale or undetermined → SCOPE_REVIEW_REQUIRED
```

`reviewedFootprint` stays, demoted to the role already adjudicated: discovery evidence, never the
freshness authority. `undetermined` is an evidence disposition inside scope resolution and **not** a
tenth `STATE`; `REACHABLE`'s gap stays exactly `["BYPASS_USED"]`.

## Built

| Module | Holds |
|---|---|
| `scripts/gitfacts.mjs` | The only place a git call for discovery lives. Zero is never inferred: non-zero exit throws, non-empty stderr throws **even on exit 0**, and an empty listing over a non-empty directory throws `DISCOVERY_INCONSISTENT`. No path returns `[]` on failure |
| `scripts/glob.mjs` | The exclusion subset. An unsupported construct is a **hard error, never a silent non-match** |
| `scripts/digest.mjs` | `RESOLVER_VERSION`, both digests, `compareSurface`, and `proposeSurface` |
| `scripts/scope.mjs` | The comparison wired in behind the existing footprint checks |
| `scripts/footprint.mjs` | Signals now carry every location, not one exemplar per kind — see below |

## Two findings the falsifiers produced

**1. Discovery cannot see into the directories most likely to be excluded.** ADR 0007's first bound
was written as *"discovery scans the whole repository, including excluded paths"*. It does not:
`footprint.mjs` skips a fixed list of directory names — `vendor`, `node_modules`, `dist`, `build`,
`.next`, `site-packages` — which are exactly the names a reviewer reaches for. **An exclusion naming
one of them has no bound on it at all: not content, and not signals.** Found when the bound's own
falsifier was pointed at `vendor/**` and did not fire. The ADR is corrected, arm 2 proves the bound
where discovery can see, and **arm 2b pins the gap** so it stays a measured property. Widening
discovery's reach is a change to detection with its own false-positive cost and is not made here.

**2. Discovery recorded one exemplar file per signal kind.** So a model file inside an excluded tree
was invisible whenever any file inside the surface already carried the same kind — the common case,
and the one an under-declaring reviewer produces. `signals` now carry every location, capped at 25
with an occurrence count. `kinds` and the footprint digest are unchanged, so `reviewedFootprint`
means exactly what it meant.

## Acceptance — both branches of every fork

```text
excluded-path content growth        → determination remains current
excluded-path signal appears        → SCOPE_REVIEW_REQUIRED
tracked file added inside surface   → stale
exclusion widened after review      → stale, and distinguishable from content change
resolver version changed            → stale, reported as a version change
current surface not reproducible    → undetermined → SCOPE_REVIEW_REQUIRED
no recorded surface                 → undetermined  (no back-filled historical digests)
```

Plus the two that justify the slice existing:

- **C-A falsifier** — identical kind set, materially changed content, determination goes stale. The
  arm asserts its own premise first: if the kind set or its digest ever moves, the old model would
  have caught the case and the arm proves nothing.
- **Inverse control** — 41 files of vendored churn carrying no signal, and the determination stays
  **current**. Proof the mechanism did not collapse back into whole-repository churn, which is the
  failure that trains reviewers to re-paste without looking.

## Consequence accepted, and it is a breaking one

**Every pre-existing determination is now `undetermined`** — a footprint basis alone no longer
establishes currentness, and a digest computed today cannot be written into a determination dated
last month, because that would assert somebody looked at this content then. Nobody did. Existing
fixtures across three suites were updated rather than grandfathered.

`resolveScope` also needs an `observeSurface` seam, and a caller that supplies none gets
`undetermined` rather than a pass. A governed repository that is not a git repository has no tracked
content, so it has no establishable surface — also `undetermined`, and correct.

## Not in this slice, deliberately

The **total ratchet** and the **~400-cell portfolio matrix**. This establishes what *one trustworthy
cell* means; making that model total across the portfolio is the next slice, and enumerating cells
before knowing what a cell asserts is the wrong order. Exclusions being ratchet fields is recorded in
ADR 0007 as a requirement, not implemented.

Also absent: any CLI for the surface, and any change to the packs' inverted staleness check — that is
their defect, on their release cycle.
