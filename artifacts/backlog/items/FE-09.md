## What

`BYPASS_USED` is a defined state with settled semantics and no code path that can produce it.

## Why

An authorised bypass is an event that happened, and a governance system that cannot see it reports a
world in which it did not.

## Notes

**Blocked on data, not on design.** GitHub exposes bypass events only through audit-log endpoints
this enforcer cannot assume are available. The semantic is settled in
[ADR 0003](../../adr/0003-the-enforcement-root.md) and the state is deliberately not produced until
the data can be read.

`REACHABLE` records the gap and a test asserts it — so this is the *only* unreachable state, and it
cannot quietly acquire company.
