## What

The capability gaps the README states plainly under *What this does not do yet*: repository
discovery, platform adapters beyond GitHub, real reviewer identity, reachable bypass detection, and
composition across more than one standard.

## Why

Stated plainly in the README because an enforcer that overstates its reach is worse than none. This
epic exists so those statements have somewhere to live besides prose.

## Notes

None of these is scheduled. They are seeded from the README's own list so that a future reader can
tell an acknowledged gap from an unnoticed one — not because a decision has been taken to build
them.

The standing rule for schema growth applies throughout: a field is added when a pack forces it, not
when it seems useful.
