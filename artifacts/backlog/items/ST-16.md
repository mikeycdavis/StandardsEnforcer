## What

[ST-15](ST-15.md) shut one shape. This story closes the rest of the same hole.

> **Acceptance property.** Any assurance verdict derived from an empty subject must fail, whatever
> shape derived it — independent of whether an accumulator was built.

## Why

ST-15's mechanism is real and its falsifier is red on `main`. But its discriminator recognises
exactly one shape: *an array declared empty, pushed to, then asserted empty* — an accumulator over
an iteration. That is what "derives a verdict from a collection" was operationalised as, and it is
narrower than the property [EP-06](EP-06.md) claims.

Measured on `main@3c02014`, with ST-15's mechanism present and its own probe correctly red. Three
further tests were added to the authoritative surface, each with an empty subject and a passing
verdict, none of them building an accumulator:

```js
// 1 · derived, not accumulated
const offenders = files.filter((f) => f.includes("FORBIDDEN"));
assert.deepEqual(offenders, []);

// 2 · asserted inside the iteration, so nothing survives it to inspect
for (const f of files) assert.ok(!f.includes("FORBIDDEN"), `${f} is malformed`);

// 3 · a predicate that is vacuously true on an empty subject
assert.ok(files.every((f) => !f.includes("FORBIDDEN")));
```

```
surface 38 | probes enumerated: 3
393 tests, 363 pass, 0 fail, 30 skipped
✔ probe-every · every source file is well formed
✔ probe-filter · no source file contains a forbidden marker
✔ probe-inloop · every source file is well formed
```

All three were enumerated by [ST-13](ST-13.md)'s surface, all three executed, and nothing objected
to any of them. **The guarantee EP-06 states is therefore not yet established** — only the
accumulator route to violating it is closed.

Shape 2 deserves particular note: it has no collection-valued verdict at all. A discriminator that
looks for a verdict *about* a collection cannot see it, because the verdict is about each element
and there were no elements. Any mechanism that closes this story has to reason about the subject
being iterated, not only about the value being asserted.

## Acceptance

Red-first, in this order. Each step evidenced by execution, not by reading.

1. **The three falsifiers exist first**, as newly enumerated tests: an empty subject with a
   `filter`/`map`-derived verdict; an empty subject with assertions only inside the iteration; an
   empty subject with an `every`/`some` predicate.
2. **Prove all three currently pass** against the base this work starts from. A falsifier never
   observed passing has not established the defect. (Observed above on `3c02014`; re-observe against
   the actual base, since that measurement will be stale by then.)
3. **Implement a standing mechanism over the authoritative test surface** — subject `testFiles(ROOT)`
   — that rejects any assurance verdict derived from an empty subject, **independent of accumulator
   shape**. All three probes must go red.
4. **Legitimate existing tests stay green.** The full surface passes with the mechanism in place. A
   mechanism that reddens honest guards has replaced one false verdict with another, and this
   story's discriminator is broader than ST-15's, so the risk of that is higher, not lower.
5. **The mechanism proves its own liveness**, as [ST-11](ST-11.md) requires of any structural guard:
   shown to fire on a planted violation and to stay silent on the remedy. ST-15's mechanism failed
   this on its first attempt — its specimens were string data, invisible to a scanner that stripped
   comments but not string bodies — so verify against a real file, not only a string.

## Explicitly not a solution

- **Extending ST-15's accumulator list with more shapes.** An enumeration of known spellings loses
  to the next spelling; this is the alias-list weakness that [ST-14](ST-14.md) had to replace with
  derivation, one level up.
- **Requiring every test to assert a non-empty subject by convention.** That is the prose rule
  ST-15 exists to have replaced.
- **Test counts, coverage thresholds, or naming conventions.** Ruled out for ST-15 and ruled out
  here for the same reason: each is fully satisfiable while all three probes above still pass.

## Progress

**2026-08-28, round one** ([evidence](../../evidence/2026-08-28-subject-liveness.md), merged as
`61e8bb7`). The mechanism landed and all three probes went red. Fourteen attack shapes: twelve
rejected, **two escaped** — a ternary and a `.join(",")` verdict — so the story stayed open.

**2026-08-28, round two** ([evidence](../../evidence/2026-08-28-subject-liveness-round-two.md)).
Both escapes closed, and the reason they escaped turned out to be structural rather than two missing
rules: `consumptions()` enumerated the **sinks** a derived collection could drain into, so it failed
open on every sink it did not know. The fix inverts the default — `assertion-shape.mjs` enumerates
the assertions that *refute* emptiness, and anything unrecognised is flagged. Not knowing is no
longer a pass.

Nine further adversarial rounds, 178 shapes. **No round found zero escapes**; the counts were
7, 8, 6, 2, 3, 4, 4, 2, 1 against the mechanism as it stood when each round began. Nine defects were
found in the mechanism itself, seven of which flagged an honest test. Five more genuine
under-proofs were found in the existing suite and each strengthened by one line.

**2026-08-28, round three** ([evidence](../../evidence/2026-08-28-verdict-language-closure.md)). The
premise itself was made checkable. Round two's control asked whether each surface file imports
`node:assert`, which admits a file that imports it *and* reaches its verdict elsewhere; three such
files now sit in `test/fixtures/subject-liveness/unsupported/`, each passing that control and
escaping the liveness rules.

The replacement is a closure argument rather than a list. Every call has a root identifier, and it is
bound by an import, bound in the file, a language global, or free — and only the fourth is unreadable.
`test-support/verdict-language.mjs` enumerates the first three and reports the rest, so an unreadable
verdict form makes the file **UNSUPPORTED**, which is an offender and never a skip. Measured: 36 of 36
files supported, zero free callees, zero bare-specifier imports. The admitted assertion vocabulary
(ten forms, 1,025 calls) is stated and checked against the surface in both directions, and every
admitted form is proved not to be a fail-open sink.

Resolving imported helpers turned up a defect in `stripComments`: a `/` inside a regex character class
ended the literal early and blanked live code in three production modules, invisible to every scanner
here. Fixed; no test outcome changed.

**Two further rounds.** Round eleven found ten escapes of twenty and does **not** count, because the
mechanism was modified during it — its faults were `assertingHelpers` enumerating declaration
syntaxes, and `assert` escaping into a value position, both fixed by inverting rather than extending.
Round twelve, run against a mechanism it did not modify, found **six escapes of twenty**.

**Still open on six shapes**, all in `test/fixtures/subject-liveness/escapes/` with `KNOWN_ESCAPES`
checked against the directory both ways. Five are one fault: attribution is by NAME, and a function is
a VALUE that flows — out of a destructuring, out of a return, into an argument, through a derived
collection, behind a computed key. Closing them needs data flow, not another binder form. The sixth is
a subject shape (`for (const f of files?.list)`).

The list grew from one to six because the measurement reached further, not because the gap opened:
every one of these escaped round two's mechanism as well, and none had been attacked with.

**The close condition is unchanged and unmet:** an adversarial round that finds nothing, run against
a mechanism it did not modify. Twelve rounds have been run and none has delivered one.

## Notes

**Scope.** This repository's own assurance surface, per EP-06's boundary — not a guarantee offered
to governed repositories.

**Do not close EP-06 when this closes.** Evaluate the parent at the parent level afterwards, as on
2026-08-27 and again on 2026-08-28, when neither a full child count nor a single shut falsifier
established it. The reasonable expectation is that this story narrows the gap rather than closing
it, and the honest close condition for EP-06 is a falsification attempt that fails to find a fourth
shape — not the absence of one having been tried.
